# Team Version Control Project

## Aim
To create a GitHub repository and implement version control using Git and GitHub for team collaboration.

## Project Description
This project demonstrates how multiple team members can work on different modules using separate branches and combine their work through pull requests.

## Modules
1. **Login Module:** Accepts username and password and validates the login credentials.
2. **Dashboard Module:** Displays the welcome message and dashboard menu options.

## Branches Created
- main – Main project branch.
- module-login – Login module development.
- module-dashboard – Dashboard module development.

## Tools Used
- Git
- GitHub
- Visual Studio Code
- Python

## Implementation Workflow
1. Created a GitHub repository named Team-Version-Control.
2. Cloned the repository into Visual Studio Code.
3. Created separate branches for individual modules.
4. Developed the Login and Dashboard modules.
5. Committed and pushed changes to their respective branches.
6. Created pull requests for both modules.
7. Reviewed and merged the pull requests into the main branch.
8. Created a merge conflict by modifying the same file in two branches.
9. Resolved the conflict by combining the required changes.
10. Updated the README file to document the workflow.

## Conclusion
Successfully implemented version control using Git and GitHub. Repository creation, branching, committing, pushing, pull requests, code review, merging, and conflict resolution were demonstrated.
